# Fomo Lens · Fomo放大镜

[English](README.md) · **中文**

在 **Fomo、GMGN 和 XXYY** 用同一张卡查看代币叙事、Fomo 观点、持有人和持仓占比。XXYY 的 `www.xxyy.io`、`pro.xxyy.io` 及站内新旧两版界面均支持。

[下载 v0.9.21](https://github.com/mickeyhogen/fomo-helper/releases/download/v0.9.21/fomo-helper-v0.9.21.zip) · [使用说明](https://hogen.pro/fomo-helper/) · [隐私说明](PRIVACY.md) · [更新日志](CHANGELOG.md) · MIT · By [@0xHogen](https://x.com/0xHogen)

## 相比 v0.9.8 更新了什么

- **三站合一**：打开代币页默认出卡，悬停代币行可预览；XXYY 收藏、钱包监控和新旧界面都能识别。
- **Fomo 数据同步可读**：Thesis、Holders 和持仓占比统一来自 Fomo。先在同一浏览器配置中登录 Fomo；读取失败时给出对应代币的 Fomo 入口与重试提示。
- **新增 Fomo 持仓横栏**：已读取持仓金额合计 ÷ 页面市值，同时显示已读人数 / 总人数。覆盖不完整标 `≥`，读不到不会伪造为零。
- **修复当前代币读取**：XXYY 池子地址先解析为实际 CA，支持 Robinhood V4 池。EVM 地址大小写统一后，当前页与悬停能读到同一叙事；Solana 地址保留大小写。
- **断线恢复与关闭后重开**：短暂失败自动补试一次；手动重试叙事时保留已读到的 Fomo 内容。关闭后留下可拖动的小放大镜；重新加载扩展时自动连接已打开的页面。
- **中英文兼容**：卡片、设置、加载和登录提示均有中英版本。观点保留原文；本地翻译取决于浏览器支持。

## 卡片内容

**Meta**：DeBot 叙事、评级理由及来源推文。起源和理由默认展开，传播等细节可点开；副池信息来自 DexScreener。

**Thesis**：按点赞排序展示最多 30 条持有人观点，保留 Fomo 的总数与截断提示，行头带仓位和盈亏。Fomo 评论流可读时可切最新排序。

**Holders**：已读取仓位中最大的 6 位，展示盈亏及持有时长，悬停看平均买入价。持仓横栏按**全部已加载行**计算，不只算这 6 位；它不是完整链上持仓统计。

在代币行停留约 0.6 秒可预览，📌 可固定。拖动头部移动卡片，拖右下角调整大小，双击头部恢复位置和大小。关闭后的放大镜可拖动、可用键盘操作并记住位置；卡片布局按站点分别保存。

## 安装与升级

支持 Chrome、Edge、Brave；不支持 Safari、Firefox。

1. 下载 ZIP，完整解压到固定的 `fomo-helper` 文件夹。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启开发者模式，点“加载已解压的扩展程序”，选择含 `manifest.json` 的文件夹。
3. 停用旧的 Fomo / GMGN / XXYY 独立版本，避免重复弹框，并允许扩展访问支持的站点。
4. 在同一浏览器配置中登录 [fomo.family](https://fomo.family)，再打开任一支持站点的代币页。

**从 v0.9.8 升级**：覆盖原文件夹后，在扩展管理页重新加载。公开版 ID 保持不变，原设置会保留。Chrome 若因新增站点访问提示重新启用或授权，按提示操作。首次升级后刷新已打开的网页一次，清理旧监听；之后重新加载扩展会自动重连。曾经关掉自动弹出的设置也会保留，可点放大镜或到设置中开启。

设置可调整语言、自动弹出、悬停、亮度、透明度及 GitHub 更新检查。更新检查缓存六小时，可关闭。

## Fomo 数据怎样取得

在 Fomo 上读取当前代币页已经渲染的内容。在 GMGN / XXYY 上优先读取已打开的同币 Fomo 页；没有可读页面时，会借用浏览器现有登录状态打开一张不激活的临时 Fomo 页，读取后关闭。不会点击、滚动或跳转主人已有的 Fomo 页面。

扩展不提取 cookie、登录令牌、私钥或助记词。临时页面会正常向 Fomo 加载数据，因此不能称为“零网络”。叙事、推文和池子查询会把相应 CA 或推文 ID 发给其数据提供方。没有开发者自建采集服务器或遥测。完整访问和存储说明见 [隐私说明](PRIVACY.md)。

## 遇到问题

- **没有卡片**：刷新网页，检查站点访问和自动弹出设置，或点小放大镜。
- **Thesis / Holders 读不到**：打开提示里的 Fomo 链接，确认同一浏览器已登录，等代币页内容出现后返回点 ↻。登录或加载失败不代表持仓为零。
- **数量少于预期**：Fomo 的筛选和懒加载决定可读范围，注意 `≥` 与已读人数 / 总人数。
- **叙事暂不可用**：DeBot 可能没有收录，或服务暂不可用；叙事与 Fomo 登录分开处理。
- **整页翻译后读不到**：优先用站内语言设置，或让浏览器显示原文；卡片本地翻译是另一项功能。

Fomo 数据目前支持 Solana、Ethereum、BSC、Base、Robinhood。上游改版仍可能影响抓取。2026-09-05 已补验 v0.9.21 在登录后的 GMGN Solana 私人钱包监控列表：代币悬停、点开、滚动、刷新及中英文展示均通过，观点、持有人和持仓占比与 Fomo 同币卡片一致。可读范围仍取决于 Fomo 页面实际展示的行；读不到不等于零持仓。
