# Fomo Lens：数据与交互说明

适用版本：v0.9.21。用户安装与排查见 [中文说明](../README.zh-CN.md)，访问与存储见 [隐私说明](../PRIVACY.md)。

## 三站共用的数据

Meta 读取 DeBot 公开叙事；来源推文读取 FxTwitter；池子与交易对读取 DexScreener。Thesis、Holders、持有时长、平均买入价及 Fomo 持仓占比都来自 Fomo 页面。

在 Fomo 读取当前页；在 GMGN / XXYY 优先读取已经打开的同币 Fomo 页，没有可读页面才打开不激活的临时页。已有页面的筛选、滚动和 URL 不会被修改；临时页完成、失败或换币后关闭。未登录或加载失败分别提示，不将失败显示为零持仓。快照内存缓存最多 60 秒，↻ 可强制重读。

Thesis 按点赞展示前 30 条，保留 Fomo 总数和截断提示；最新排序依赖可读的评论流。Holders 展示已读仓位中前 6 位。持仓横栏按全部已读持仓金额合计除以 Fomo 页面市值计算；未读全时显示 `≥` 和覆盖人数。星级阈值按未舍入占比计算，≥15% 一星，≥20% 二星。

## 当前币与悬停

GMGN 从代币 URL 或对应行读取 CA。XXYY 同时支持 www/pro 两个入口和站内新旧界面；池子 URL 先核对链与池标识再解析实际 CA，Robinhood V4 的 32 字节池标识不会直接交给叙事源或 Fomo。

XXYY 的 Vue、GMGN 的 React 行探针只从命中行读取代币与链，不从钱包地址猜代币。虚拟行复用、内层行重建及站点筛选重绘都有有界补探，离开或换行后旧响应作废。原生币转账中没有 token CA 时不弹代币预览。

EVM 合约查询统一成小写，与缓存键及响应身份核对一致；Solana 地址大小写敏感，保持原样。其它 CA 的响应拒绝展示。

## 展示与恢复

代币页默认精简开卡，先出加载状态再等待地址反解；关闭后不会被迟到响应重新打开。悬停需在同一行停留约 600 毫秒，可用 📌 固定。卡片和放大镜可拖动、缩放窗口后保持可达，按站点保存布局；双击卡片头部恢复位置和尺寸。

短暂叙事故障自动补试一次，持续失败后停止自动请求。手动重试叙事保留已有 Fomo 内容。扩展重新加载后检测并重连自己的页面实例；旧上下文失效不会中断新实例创建。首次从 v0.9.8 升级需刷新网站一次，以清理旧版监听。

## 语言与限制

卡片与设置支持中文 / English。Fomo 站内文字锚点兼容既有语言解析规则；整页翻译仍可能改变 DOM，必要时切回原文。原始观点保留源语言，本地翻译依赖 Chrome 的支持与语言包。

数据源与网站可改版或暂不可用。Fomo 读取支持 Solana、Ethereum、BSC、Base、Robinhood；页面未加载到的持仓不会被臆补。GMGN 私有钱包监控的安装态测试和真实公开代币页验收分开记录。
