Fomo叙事镜

在 fomo.family 浏览代币时，把 DeBot 叙事、社区观点、持仓者结构与来源推文 聚成一张浮动卡片——不用为了看一眼叙事另开三个标签页。

零后端 · 不采集任何数据 开源 MIT 只在 fomo.family 注入 Chrome / Edge / Brave
下载最新版 zip GitHub 源码 最新版本见 GitHub Releases

实际效果：卡片默认停靠在左栏右缘，压在图表区上方，不遮代币信息条、不吃 Holders 表。

01

它做什么

进入任意代币页，卡片自动弹出（可关）。顶部三个标签页，答的是同一个问题的三个层次： 这币的叙事是什么，社区在拿什么理由持仓，都是谁在拿。

叙事观点持仓者

叙事 — 这币是什么

DeBot 的叙事分析全量呈现：起源与评级理由默认摊开，传播 / 开发者 / 来源推文收成一行标题点开看。 第一屏先给结论，不是先给篇幅。占位套话（"暂无"、"未发现"之类）自动过滤，不占卡片高度。

叙事观点持仓者

观点 — 持有人自己怎么说

Holders 表里每个持有人对这只币写下的 thesis：按点赞降序全量列出、去重，行头带这位持有人的 仓位与盈亏——先看他押了多少钱，再听他讲道理。非中文观点自动补译文，原文保留。

悬停预览 — 不用点进去

鼠标在左栏 Alerts / Feed 的某一行上停住 0.6 秒，卡片浮出该币预览；点 📌 固定。 快速划过一串行不会误触发。

一切可调

自动弹出三档（精简 / 全展开 / 关闭）、默认语言、悬停预览开关，都在扩展图标的设置面板里。 还可以接入你自己的分析源（可选，见下方数据边界）。

02

数据边界 — 装之前先说清

一个装在交易网站上的扩展，你最该问的不是它有什么功能，而是它把数据发给了谁。逐条回答：

本扩展没有服务器。

不存在"我们的后端"。没有账号体系、没有遥测、没有统计上报。你的名单和设置只存在你浏览器本地的 chrome.storage 里，卸载即清除。以下四处是它全部的数据接触面——manifest 里声明的域名你可以自己核对。

接触点用途性质
app.debot.ai拉取代币叙事分析公开接口，不登录、不带 cookie、无 key
fomo.family 页面 DOM观点与持仓者零网络：只读页面上已渲染的内容，不发任何请求，不碰你的登录态
你填的分析源「AI 判断」段可选。不填就完全不存在；填了才申请该域名授权
api.fxtwitter.com叙事来源推文正文公开只读，不登录、不发帖
自定义分析源为什么卡得很死：那条请求由扩展后台代发、不受页面 CORS 约束。所以默认只收 https 公网地址， 内网 / 环回 / 链路本地 / CGNAT 段与裸主机名在发出前一律拒绝（SSRF 防线，一个字节都不会发出去）。 给自建内网源保留了一个默认关闭的「高级·仅自用」开关，开了也仍需逐域名显式授权。 完整版见 隐私说明。
03

安装

以「已解压扩展」方式加载，不经过应用商店，全程约一分钟。Chrome、Edge、Brave 通用（Safari / Firefox 不支持）。

  1. 下载并解压

    点上方「下载最新版 zip」。 双击 zip 自动解压出 fomo-narrative-lens 文件夹。 在 zip 上右键 →「全部解压缩…」解压出 fomo-narrative-lens 文件夹。 不要双击进入 zip 直接用——那是个预览视图，Chrome 读不到它。

  2. 把文件夹放到一个固定位置

    建议从「下载」挪到固定目录，比如 ~/Documents/Extensions/。 建议从「下载」挪到固定目录，比如 C:\Extensions\。 浏览器每次启动都从这个文件夹读取扩展——放在下载目录里，哪天清理下载就把扩展清没了。

  3. 打开扩展页，开启开发者模式

    地址栏输入 chrome://extensions（Edge 用 edge://extensions）， 打开右上角的「开发者模式」开关。

  4. 加载已解压的扩展程序

    点「加载已解压的扩展程序」，选中刚才那个含 manifest.json 的文件夹。 工具栏出现图标即安装成功。

  5. 打开 fomo.family

    点进任意代币页，卡片自动弹出。没有别的初始化步骤——不需要登录什么、不需要同步什么。

更新方式：下载新版 zip，解压覆盖原来的文件夹，回 chrome://extensions 点该扩展卡片上的刷新圈 ↻（或重启浏览器）。配置不会丢——扩展 ID 是固定的， 即使你把文件夹挪去别的位置重装，名单和设置也都在原地。想收到新版本提醒，在 GitHub 上 Watch → Custom → Releases 即可。
04

常见问题

装好了，页面上什么都没出现
它只在 fomo.family 生效，其它网站上没有任何注入。先刷新 fomo 页面； 仍没有就到 chrome://extensions 确认扩展已启用，点刷新圈 ↻ 再回来。 没有自动弹卡时，代币页右下角会有一个「叙」圆钮，点它也能打开。
观点 / 持仓者标签页是灰字「把 Holders 表滚动到可见」
这两页读的是 fomo 页面上的 Holders 表，而 fomo 的表格是懒加载的。不用你操作： 表一渲染出来，卡片会在 25 秒内自动补上数据；把 Holders 表滚动到可见能立刻触发。灰字不是报错。
这个币显示「没有叙事」
DeBot 没收录这个币，这是数据侧的事实，不是扩展故障。观点 / 持仓者两页不受影响。
它会碰我的 fomo 登录态或钱包吗
不会。扩展不向 fomo 发任何网络请求（观点/持仓是读页面已渲染的内容）， 不读取、不存储、不外发任何令牌，更没有触碰钱包的权限。详见上方「数据边界」与 PRIVACY.md。
为什么不显示星级评分
DeBot 的 1–5 星是主观打分，公开版默认不显示，避免被当成投资建议； 评级理由的文字保留——理由是有用的上下文，分数不是。
更新会丢配置吗 / 换台电脑呢
同一浏览器内更新、挪目录、重装都不丢（扩展 ID 固定，配置跟着 ID 走）。 换电脑 / 换浏览器配置不跟随——所有数据只存本地，这是隐私设计的代价。
fomo 改版之后有些内容抓不到了
观点 / 持仓者靠页面文本特征解析（fomo 的 CSS 类名是哈希化的，没法依赖）， 大改版可能让它们退化成灰字提示；叙事页不受影响。遇到了请开 GitHub Issue， 修起来通常很快。
